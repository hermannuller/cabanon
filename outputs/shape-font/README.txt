Shape Grid Trial — 26-glyph prototype

Install both TTF files. Select Shape Grid Trial and style Original / Opposite.
Legacy applications may list each style as a separate font family.
Opposite = horizontal reflection. Only A-Z and space are mapped.
All advances: 1000 units; em: 1000; ascent: 1000; descent and line gap: 0.
Set tracking to 0 and line spacing to 100% for square-grid composition.
